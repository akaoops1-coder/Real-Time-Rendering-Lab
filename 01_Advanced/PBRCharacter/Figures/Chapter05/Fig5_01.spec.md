# Figure 5-1 Specification

Purpose: Skin / Hair / Eye의 구현 책임, 공유 Scene 조건과 서로 다른 증거 경로를 구분한다.

Type: Concept / Architecture Diagram. 실제 Unreal Graph, Render, 배정 감사 또는 GPU 측정 화면이 아니다.

Input: Chapter01~04의 Material 입력 계약과 Chapter05의 증거 상태다. Skin / Hair / Eye는 별도 Surface이며 하나의 BSDF 합성 Graph를 뜻하지 않는다.

Flow: 왼쪽에서 오른쪽으로 Material 구현 → 같은 Scene 관찰 조건 → Visual / Debug / Timing의 증거 책임을 읽는다. 화살표는 책임·관찰 관계를 단순화한 것으로, 실제 GPU Pass 실행 순서나 모든 Material의 상속 관계가 아니다.

Current scope: 실제 얼굴 관찰은 존재하나 최신 배정 감사·통제된 최종 pair는 TODO다. Debug에는 과거 자료가 있으며 최신 Character Matrix는 TODO다. GPU Timing은 격리 Hair PDO만 측정했고 전체 Character는 보류다.

Layout: 1640×990, White Background, English short labels, Arial. Primary #2F6BFF / Success #43A047 / Warning #FB8C00 / Neutral #9E9E9E. 색과 텍스트를 함께 사용한다.

Sources: Chapter01_ProductionPBRMasterMaterial.md, Chapter02_ProductionSkinShader.md, Chapter03_ProductionHairShader.md, Chapter04_ProductionEyeMaterial.md, Chapter05_CharacterIntegrationAndValidation.md. 실제 측정·실행하지 않은 수치 예시는 포함하지 않는다.
