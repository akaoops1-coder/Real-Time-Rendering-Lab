GPU Time ⓘ

GPU가 프레임을 처리한 시간입니다. 대표값은 각 Run Median의 중앙값이며 낮을수록 빠릅니다. 장면 전체의 GPU 시간이고 특정 Material의 단독 비용이 아닙니다.

Delta ⓘ

B − A입니다. 음수는 B의 관측 시간이 짧고 양수는 길다는 뜻입니다. 성능 개선·증가는 Confidence와 Impact 판정을 함께 확인합니다.

Noise Floor ⓘ

최소 정책값과 AA·A·B Run Median Range 중 최댓값입니다. |Delta|가 이 값보다 커야 비교 확정의 한 조건을 만족합니다. 장비의 공식 오차나 신뢰구간이 아닙니다.

Confidence ⓘ

A/A 연결·조건 일치, 반복 수, 반복 안정성, Delta와 Noise Floor를 검사한 RTR 정책 결과입니다. RELIABLE은 통계적 유의성이나 신뢰구간을 의미하지 않습니다.

Impact ⓘ

A/B로 달라진 GPU 시간의 목표 프레임 예산 대비 비율입니다. Confidence가 충분할 때만 GREEN·YELLOW·RED·IMPROVED로 확정합니다. Budget 등급과 별개입니다.

GPU Budget ⓘ

각 상태의 절대 GPU 시간 / 목표 프레임 예산입니다. 안정적인 GPU 값에서 평가하며 A/B 차이가 불확실해도 GREEN일 수 있습니다. 전체 시스템의 목표 FPS 달성을 보장하지 않습니다.
