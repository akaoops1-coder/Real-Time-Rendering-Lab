# Fig4_07 — Radial UV Remapping Geometry

## Purpose
Destination UV의 방향은 유지하면서 Source Texture에서 읽을 반지름만 바꾸는 inverse sampling을 설명한다. 실제 Unreal Render가 아닌 Concept Example이다.

## Inputs and Output
- Center=(.5,.5), original PupilRadius=.055, IrisRadius=.16.
- PupilScale=1.2 → NewPupilRadius=.066; IrisScale=1 → NewIrisRadius=.16.
- Sample output radius r=.10 → t=(.10-.066)/(.16-.066)=.3617021277 → SourceRadius=.0929787234.
- Float2 UV/Delta/Direction/ScaledUV; float1 Length/SourceRadius.
- Left → Right arrow denotes inverse texture sample lookup, not surface displacement. Left is destination/image position; right is the source lookup UV produced by the Material Function.
