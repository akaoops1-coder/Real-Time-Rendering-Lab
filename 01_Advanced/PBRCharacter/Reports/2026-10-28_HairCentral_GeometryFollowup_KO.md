# RTR Advanced — 중앙 패턴의 투과 그림자 / 메시 후속 조사

2026-10-28 KST · UE 5.8.3 · **Final Status: Unresolved**

이 문서는 [앞선 조사](2026-10-28_HairCentral_ShadowHighlight_Investigation_KO.md)의 후속 기록이다. 사용자가 메시 수정은 직접 진행할 수 있다고 밝힌 후, 수정할 부위를 특정하는 데 초점을 맞췄다. 기존 보고서와 에셋은 덮어쓰지 않았다.

## 1. Problem Description

같은 원본 TestScene, `M_Hair_Master`, `MI_Female01_hair`의 뒤통수 상단 중앙 패턴을 다시 확인했다. 앞선 조사에서 확인한 Hair 자기 그림자 연동을 바탕으로, 이번에는 **Hair BSDF 평가 전의 그림자 버퍼**와 **실제 원본 Hair Card 기하**를 대조했다.

기준 Camera는 위치 `(33.859891, -0.294924, 165.212573)`, 회전 `(2.6, -179.164474, 0)`, FOV `60`이다. 광원 회전 `(-33, -43, 112.360672)`, RT Shadow 8 samples, Hair / Head Cast Shadow ON, 기존 Backlit `.1`, Roughness `.35`, Specular `.5`, Scatter `.1`, PDO `.1`을 유지했다. 추가 조사 기준 상태를 보관했다.

## 2. Root Cause Analysis

**이번에 더 좁힌 결론: 중앙 패턴은 카드 레이어의 기하 두께 차이가 투과 그림자 신호에 나타나고, 그 신호가 Hair 반사를 변조하는 현상과 대응한다.** 특정 메시 결함 하나를 고치면 완전히 해결된다는 검증은 아직 하지 않았다.

### GPU에서 확인한 신호

`vis`로 RT 원시 Occlusion과 Denoiser 출력의 채널을 나누어 검사했다. 최종 색·섬유 광택을 보여주지 않는 **투과 그림자 채널에도 중앙의 밝고 어두운 띠가 이미 존재**했다. Head Shadow를 꺼도 이 띠가 남았고, Hair Shadow를 끄면 중앙 띠가 사라지면서 Head의 큰 차폐 경계가 드러났다. 두 그림자를 함께 끄면 그 경계도 사라졌다.

따라서 이번 중앙 띠를 Tangent / Specular 입력만의 불연속으로 설명하기는 어렵다. 기존 Backlit 값은 시험 중 변경하지 않았으며, 이 패턴은 Backlit을 평가하기 전의 그림자 신호에서 관찰했다.

설치된 UE 소스에서 다음 경로를 확인했다. 코드는 변경하지 않았다.

| 위치 | 확인한 처리 |
|---|---|
| `RayTracingOcclusionRGS.usf:530–565` | Hair에서 광선을 반대 방향으로 추적한 교차 위치로 Thickness를 계산하고, `exp(-Density * Thickness)`로 투과 신호 계산. 이 분기의 Hair Density는 `1` |
| `RayTracingOcclusionRGS.usf:852–896` | 원시 출력의 A 채널에 투과 값 저장. Denoiser 모드에 따라 다른 채널의 의미는 달라짐 |
| `Common.ush:1195–1218` | Light Attenuation 저장 시 제곱근 인코딩, 읽을 때 제곱으로 복원 |
| `SubstrateEvaluation.ush:1171–1179` | 기존 Backlit 전달을 유지하면서 Hair 응답을 계산하고, 통합 반사 값에 `ShadowTerms.TransmissionShadow` 적용 |

이 식은 카드에 표시되는 섬유색과 별도로 **광원 방향의 기하 거리 차이**를 강한 밝기 차이로 바꿀 수 있다. 이 동작을 확인한 것이며 엔진 버그로 단정한 것은 아니다.

### 원본 메시를 읽어 확인한 구조

실제 에디터의 StaticMesh LOD0 Render Data에서 위치·삼각형·노멀·UV를 읽었다. Mesh Asset을 복제하거나 수정하지 않았다. 사용 중인 Opacity Texture도 읽기 전용으로 내보내 계산에 사용했다.

- Render Vertex `18,587`, Triangle `24,240`.
- 같은 위치의 분리 Vertex를 묶어 계산한 연결 카드 그룹 `135개`.
- 퇴화 삼각형 및 같은 좌표의 정확한 중복 삼각형은 사용한 허용오차 범위에서 `0개`.
- 중앙 ROI에서 광원 방향으로 `7,060개` 표면 샘플을 추적했다. 카드별로 가려지는 거리의 분포가 크게 달랐다. 예를 들어 A와 E 그룹의 중앙값은 각각 약 `8.86 cm`, `11.62 cm`, C 그룹은 약 `1.70 cm`였다. 이것은 **레이 경로의 거리**이며 카드 간 수직 간격이나 권장 수정량이 아니다.
- 독립 계산의 투과 예측과 GPU 표시 채널은 점별 상관 약 `0.65`, 제곱근 인코딩을 가정하면 약 `0.68`이었다. 이는 근사 대응의 보조 근거이며 정확도 보증·개선율·단독 인과 증명이 아니다.
- 주요 수신 카드 5개와 주변 카드의 실제 비공면 교차를 검사했다. 원본 Opacity를 고려한 교차 중 화면에서 보이는 표면의 약 `1.5 mm` 이내에 있는 선분 `40개`를 찾았다. 하나의 연속 교차선이 여러 삼각형 선분으로 집계되므로 40개의 독립적인 결함이라는 뜻은 아니다.

근거: 기하 요약, 레이어 광선 분석, GPU 대응, 교차 분석.

### 메시 수정 검토 부위

원본, 투과 그림자, 수신 카드

왼쪽은 원본 Crop, 가운데는 GPU 투과 그림자 표시, 오른쪽은 실제 기하에서 분리한 카드 색상 오버레이다. 오른쪽 색은 진단 표시이며 Material 변경이 아니다.

| 가이드 | 진단 카드 ID | 검토 우선순위 |
|---|---|---|
| A / 하늘색 | 80 | B와 교차하며 중앙을 덮는 레이어 |
| B / 주황색 | 34 | A 및 C와 교차하는 중앙 레이어 |
| C / 연두색 | 74 | B·D 및 주변 카드와 교차하는 레이어 |
| D / 자홍색 | 38 | C와 맞물리는 상단 레이어 |
| E / 노란색 | 25 | 주변 57번 카드와 교차하는 인접 레이어 |

**첫 메시 수정 실험은 A–B 및 B–C 구간을 우선 검토하는 것이 타당하다.** 외곽 실루엣·UV·섬유 방향·전체 볼륨을 유지하면서, 서로의 앞뒤 순서가 바뀌는 교차와 급한 레이어 깊이 변화를 국소적으로 정리하고 같은 조건으로 다시 비교한다. 카드 전체를 제거하거나 전체 밀도를 낮추는 수정량은 이번 조사에서 입증하지 않았다.

실측 교차선

청록색은 위 조건을 만족한 실제 카드 교차선의 투영이다. 교차선과 검은 띠 전체가 일대일로 같다는 의미는 아니다. 여러 카드의 그림자 투영과 투과 거리 차이가 함께 작용한다.

진단 카드 ID는 이번에 계산한 연결 성분 번호이며 Blender Object 이름이나 원본 Face Index가 아니다. 원본을 찾을 때 사용할 UE LOD0 Vertex 위치 목록을 함께 제공한다. 좌표는 Mesh Local, 단위 cm다. 가이드 구성 정보에 색상·인덱스 기준을 기록했다.

## 4. Applied Fix

**최종 적용 수정 없음.** 사용자 메시 수정 검토를 위한 위치와 근거를 남겼다. Mesh, Material, Instance, Texture, Material Function, Engine Shader는 수정·저장하지 않았다. 새 UE Asset도 생성하지 않았다.

기존 Backlit 전달 수정과 `Hair_Backlit = .1`은 유지했다. Camera, FOV, 광원 회전, Hair / Head Shadow, Game View를 복구했고 `vis`를 껐다. 기록한 CVars도 기준값과 같다. 미저장 Content / Map Package는 없고 모든 진단 Tick Callback을 해제했다. 이번 후속 조사에서는 에디터 재시작이나 Package Reload를 수행하지 않았다.

## 6. Remaining Limitations

이번 결과는 **카드 배치와 Hair 투과 그림자 모델의 상호작용**을 강하게 지지한다. 하지만 정상적인 카드 교차와 수정이 필요한 교차를 자동으로 구별하거나, 제시한 A–B / B–C 수정만으로 모든 패턴이 없어짐을 검증하지는 않았다. 뒤쪽의 다른 카드도 광원 방향 차폐에 기여하므로 수신 카드만 고치면 충분하다고 단정할 수 없다.

독립 광선 계산은 Hair LOD0와 원본 Opacity의 근사다. GPU Texture 압축·Mip·PDO·광원 크기·Bias·시간 필터 및 Head Ray Geometry를 완전히 재현하지 않는다. 측정 거리나 상관값을 권장 이동량으로 사용하지 않는다. 메시 수정량은 작은 국소 변경 후 실제 UE 비교로 결정해야 한다.

## 7. Final Status

**Unresolved — 메시 수정 검토 부위와 투과 그림자 경로를 특정했다.** 해결 불가능 판정이 아니며, 현재 근거로는 메시의 중앙 레이어 교차·깊이 변화를 우선 수정 시험하는 방향이 합리적이다. 수정 완료 및 품질 승인에는 수정된 원본 메시의 동일 조건 Before / After가 필요하다.
