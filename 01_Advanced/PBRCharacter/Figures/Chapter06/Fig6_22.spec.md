# Fig6_22 — Mobile Hair Production Material Pin Map

## Purpose

저장된 `M_Mobile_Hair_Production`의 Surface 및 Custom Specular 배선을 별도 Lane으로 보여준다. 이 도식은 Graph Capture를 대신해 읽기 전용 검증 데이터를 전사한 자료다.

## Data Flow

| Lane | Inputs and processing | Material Output |
|---|---|---|
| Card Surface | Root/Tip Color × Depth Shading. Opacity와 Roughness는 별도 입력이다. | Base Color / Opacity Mask / Roughness |
| Custom Specular | Card Tangent와 Half Vector → Kajiya-Kay → Strength와 Color → LightFacing, Root 및 Depth 감쇠 → Use_CustomSpecular → Use_CSM_Visibility. | Emissive Color |

실선 화살표는 Graph를 통해 전달되는 데이터를 나타낸다. 조립 순서를 단순화하되 두 Switch의 분기 의미는 유지한다. Depth Shading `D`는 두 Lane에서 재사용된다.
