# Fig4_10 — Scale and Parallax Integration

## Purpose
Scale Function의 UV와 BumpOffset의 두 입력 및 Texture sampling의 Data dependency를 설명한다. 도식은 Intended Integration Contract이며, 전체 최신 저장 Graph의 연결 검증을 대신하지 않는다.

## Inputs / Output
- Scale Material Function output = Scaled UV (float2).
- Scaled UV branches to BumpOffset Coordinate and Distance(ScaledUV,Center) → SmoothStep(Min=.14,Max=.20) → Height(float1).
- BumpOffset Final Offset UV(float2) is shared by Base Color / Iris Mask / Pupil Mask / Iris Normal samples.
- DepthAmount and ReferencePlane retained by intended implementation; diagram does not invent current ReferencePlane numeric value.
- Arrows represent data dependencies, not runtime sequencing or physical light rays.

## Source and Limits
Referenced conversation integration record dated 2026-11-02: Scaled UV must be used for both Coordinate and Depth Height calculation. User reported improved OuterTransition Max .20. Diagram does not prove current asset save status, exact sign/normalization of BumpOffset physical depth, physical refraction, or current IrisDistance alignment. Height must not depend on the BumpOffset output UV because this creates a graph cycle.
